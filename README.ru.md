# Лабораторная работа ТПМП 8 — хранение данных, геолокация и карты на iOS

Учебная коллекция примеров на Swift и Objective-C: plist и `UserDefaults`, Core Data, Core Location, MapKit, а также два приложения варианта 3 — аудиотека и каталог парков Минска.

## Структура и технологии

- `example1`–`example7`: каталог plist, демонстрационная авторизация, геолокация, карты/геокодирование, бронирование, Core Data и прогноз погоды.
- `task2-1`: Audioteka на plist, `UserDefaults`, collection view и локализованном интерфейсе.
- `task2-2`: MinskParks на MapKit, Core Location, Core Data и погодном API.
- Swift, Objective-C, UIKit, MapKit, Core Data, Xcode.

## Сборка и запуск

Нужен Xcode на macOS. Для `example1`–`example7` и `task2-1` в каталоге проекта есть манифест XcodeGen `project.yml`: выполните `xcodegen generate`, затем откройте созданный проект Xcode. В `task2-2` уже есть `MinskParks.xcodeproj`. Запустите приложение в iOS Simulator или на устройстве. Для примеров с погодой нужен личный ключ OpenWeather. Значения `OpenWeatherAPIKey` в снимке являются placeholders: настройте свой локальный ключ и не коммитьте его. Сборки и тесты не заявляются как выполненные.

## Снимок и атрибуция

Это чистый снимок локальной рабочей копии без истории приватного репозитория. Локальная Git-история фиксирует настройку Lab 8 и коммиты документации, но не устанавливает авторство текущих незакоммиченных файлов приложений. Мой личный вклад требует ручного уточнения. Локальные архивы, скрипты загрузки, черновики отчёта и скриншоты симулятора исключены; каталоги с исходниками сохранены.

Это учебная работа, а не production-приложение. Примеры аутентификации демонстрационные.
